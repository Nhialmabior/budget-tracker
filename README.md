# SpendWise - Budget Tracker

## Project Description

SpendWise is a simple and user-friendly budget tracker designed to help users view and organize their personal financial information. The project provides a clean dashboard where users can view different spending categories and get useful budgeting tips.

## What I Have Built So Far

The current version of SpendWise focuses on the visual design and structure of the budget tracker.

The project currently includes:

* A responsive dashboard layout
* SpendWise branding and logo
* Navigation menu
* Monthly financial overview
* Spending category cards
* Food, Transport, Rent, Entertainment, Savings, and Utilities categories
* Budgeting tips section
* Embedded budgeting video
* Responsive design for smaller screens
* CSS Grid and Flexbox layouts
* Hover and keyboard-focus interactions
* Dark theme support based on the user's system preference
* Page title, favicon, and Open Graph meta tags
* A live version published using GitHub Pages

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Google Fonts
* Git and GitHub
* GitHub Pages

## Current Status

The tracker is currently focused on the user interface and visual presentation. The displayed financial values are static at this stage and the application does not yet perform automatic calculations.

## What's Coming Next

JavaScript functionality starts next week.
